Mission Statement

SagaSphere merges Viking mythology, interstellar exploration, and time‑bending sci‑fi into a social platform where every user becomes a saga‑bearing traveler. Privacy‑first, encrypted‑always, community‑driven.
Core Features

    Encrypted private, group, and instant messaging

    Reputation points, ranks, and collectible badges

    Friend requests, clans, and alliances

    Posts, comments, and threaded discussions

    Free tier plus optional premium enhancements

    Admin command deck for metrics and oversight
